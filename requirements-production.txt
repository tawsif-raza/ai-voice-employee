# "Core ML stack" (transformers/peft/trl/bitsandbytes/accelerate/datasets/

# deployment. If a future deployment re-enables the local model or RAG,
# it must go back to the full docker/Dockerfile + requirements.txt, not
# this file.
#
# requirements.txt remains the source of truth for version pins; this
# file is requirements.txt with exactly those sections removed -- keep
# it in sync by hand when requirements.txt's non-excluded sections change.
