# 🎙️ ai-voice-employee

The **AI voice employee** — custom voice models trained with **LoRA fine-tuning** for natural, on-brand speech.

## 💡 The Goal

Generic TTS voices sound generic. This project trains small, task-specific voice models (LoRA adapters) so the voice "employee" sounds consistent, natural, and recognizable across every piece of content it produces.

## 🧩 What's Inside

- LoRA fine-tuning pipeline for speech/voice models
- Training-data preparation & experiments
- Model configs and checkpoints

## 🛠️ Stack

- **Python**
- **LoRA / PEFT** fine-tuning
- **Speech & audio AI**

## 🚀 Status

Active experiments — training runs, results and documentation are being added as the pipeline matures.
